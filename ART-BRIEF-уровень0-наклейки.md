# Бриф: пять наклеек для уровня 0

Для Себастиана. Пять картинок, каждая — отдельный файл.

## Куда это идёт

Самый первый уровень игры. На столе лежит закрытая тетрадь, внизу экрана — пять наклеек. Игрок берёт наклейку и кладёт её на место: место обозначено **тонким контуром по форме самой наклейки**, напечатанным на обложке.

Отсюда главное требование ко всему набору: **пять разных силуэтов**. Если наклейки окажутся похожими по форме, игрок не поймёт, какая куда, и уровень перестанет учить.

## Что нужно

Пять наклеек в стиле игры: тот же приглушённый мир, что у кота-маскота и у логотипа — мягкие края, спокойные цвета, белая обводка по краю, как у настоящей виниловой наклейки.

Сюжеты — предметы со стола: **фотоаппарат, стопка книг, кружка какао, растение в горшке, клубок ниток**. Сюжеты можно менять на свои, если в стиле лучше ложится что-то другое, — но силуэты должны остаться разными: широкий, вертикальный, круглый, квадратный, мелкий.

## Размеры — это главное в брифе

Игра сама масштабирует наклейки и сама строит по ним контуры-места. Чтобы контур получился чистым, картинки нужны в одном формате:

| Что | Как |
|---|---|
| холст | ровно **600 × 600 px**, отдельный файл на каждую наклейку |
| наклейка | вписана по центру, поля со всех сторон **не меньше 6 %** (36 px) |
| белая обводка | ровной ширины по всему контуру, **20–24 px** |
| фон | **прозрачный**; если прозрачность не выходит — чисто белый `#FFFFFF`, без градиента и без виньетки |
| формат | PNG |

**Тень не рисовать.** Тень под наклейкой добавляет игра, нарисованная тень даст двойную.

**Текста нет нигде**: ни надписей на кружке, ни букв на книгах, ни цифр.

## Обязательные требования

- **Вид строго сверху, плашмя.** Это главная беда прошлых наклеек: предмет нарисован чуть развёрнутым, будто смотришь на него сбоку-сверху, и наклейка перестаёт быть плоской. Нужен ровный вид сверху: у кружки видно круглое отверстие целиком, а не овал; у стопки книг не видно торцов; у горшка не видно внутренней стенки. Объём — только мягкой тенью внутри рисунка, без разворота предмета.
- **Обводка замкнутая и ровная**: по ней игра строит контур места, разрывы и рваные края испортят подсказку.
- Никаких мелких висящих деталей за пределами обводки — они превратятся в мусор на контуре.
- Один предмет на наклейку, без композиций из нескольких.

## Промпт для генерации

```
A single die-cut vinyl sticker of a [camera / stack of books / mug of
cocoa / potted plant / ball of yarn], drawn as a completely FLAT
top-down icon: the object is seen from directly above, not tilted, not
rotated, no side surfaces visible, no three-quarter view.
Square image 600x600, transparent background.

The sticker has a clean white die-cut border of even width around the
whole shape, about 22 pixels wide. The object is centered with at least
6% empty margin on every side.

Muted palette, soft edges, gentle shading, cozy hand-drawn illustration
style, not glossy.
NO drop shadow, NO background, NO text, no letters, no numbers.
```

## Чеклист приёмки

- [ ] Пять отдельных файлов PNG, каждый ровно 600 × 600
- [ ] Фон прозрачный (или чисто белый, без градиента)
- [ ] Поля не меньше 6 % со всех сторон
- [ ] Белая обводка ровная и замкнутая, 20–24 px
- [ ] Тени под наклейкой нет
- [ ] Вид строго сверху: предмет не развёрнут, боковых стенок не видно
- [ ] Силуэты пяти наклеек заметно разные
- [ ] Текста нет нигде
