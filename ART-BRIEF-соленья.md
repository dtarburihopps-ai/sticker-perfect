# Бриф на перерисовку: банки с соленьями

Для Себастиана.

## Что не так с текущим листом

Четыре банки нарисованы с разными пропорциями: 0,61 · 0,64 · 0,56 · 0,68 (ширина к высоте). В игре они стоят в ряд на одной полке и должны быть одной высоты — а раз пропорции разные, ширина у всех получается разная, и ряд не сходится. Между банками появляются то щели, то нахлёст.

**Это не придирка к рисунку, а требование движка.** Игра для перфекционистов: размеры и позиции считаются арифметикой, а не подгоняются на глаз. Стикер обязан вписываться в отведённую ему клетку.

## Что нужно

**Шесть банок с соленьями, все строго одного размера и одной пропорции.**

- пропорция каждой банки: **ширина к высоте 0,63** — то есть примерно **2 : 3** (например 400 × 635 пикселей)
- банки стоят в один ряд, каждая в своей клетке одинаковой ширины
- между клетками одинаковые промежутки
- **форма и размер банки у всех одинаковые**, разное только содержимое

**Содержимое** (шесть разных, форма банки при этом одна):
1. огурцы целые
2. помидоры
3. кабачки кружочками
4. перцы
5. капуста
6. грибы

Можно заменить любое на своё усмотрение — важно, чтобы содержимое различалось с одного взгляда по цвету.

## Обязательные требования

**Одинаковая белая обводка у всех.** Толщина обводки — примерно одна десятая ширины банки, не больше. Это важно: кайма входит в габарит стикера и съедает место. На прошлом листе у бутылки колы обводка занимала пятую часть ширины, и бутылка выглядела мелкой, хотя места занимала столько же, сколько нужно.

**Банка занимает свою клетку целиком** по высоте — без больших пустых полей сверху и снизу. Крышка у верхнего края, дно у нижнего.

**Все банки стоят на одной линии.** Дно каждой — на одной высоте, вровень.

**Фон однотонный**, без текстуры и пятен: буду вырезать каждую банку отдельно.

**Ноль текста.** Ни этикеток с надписями, ни цифр.

**Стиль тот же**, что у колы, перца и апельсина: приглушённая тёплая палитра, тонкие линии, лёгкая бумажная текстура. Не мультяшно, не ярко.

## Промпт для генерации

```
Sticker sheet: six identical glass jars with different preserved
vegetables inside, in one horizontal row, evenly spaced.

CRITICAL: every jar must have exactly the same shape, the same size
and the same proportion — width to height = 2:3. Only the contents
differ. All jars stand on one baseline, lids aligned at the top.

Contents: whole cucumbers, tomatoes, sliced zucchini, peppers,
cabbage, mushrooms.

Each jar is a die-cut sticker with a thin white border of equal
thickness on all six — the border must be about one tenth of the
jar width, no thicker.

Plain flat background, no texture. Muted warm palette, soft paper
texture on the illustration itself, clean modern style.
No text, no labels, no numbers.
```

## Чеклист приёмки

- [ ] Все шесть банок одинаковой ширины и высоты
- [ ] Пропорция каждой близка к 2:3
- [ ] Обводка одинаковой толщины и не толще десятой части ширины
- [ ] Дно всех банок на одной линии
- [ ] Содержимое различается по цвету с первого взгляда
- [ ] Фон однотонный, текста нет
