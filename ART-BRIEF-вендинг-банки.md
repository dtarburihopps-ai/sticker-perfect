# Бриф: вендинг — банки

Для Себастиана. Одна картинка — один лист.

**Что за уровень.** Игрок заполняет товаром пустой вендинговый автомат. Полок пять, видов товара тоже пять, и каждый вид подходит только на свою полку: ячейка там ровно под него. Никаких подсказок в игре нет — только размер. Свой предмет встаёт в ячейку как влитой, чужой болтается.

**Отсюда главное требование: размер важнее красоты.** Если предмет нарисован другой пропорции, он либо не влезет в ячейку, либо будет висеть в ней с пустыми полями, и уровень перестанет читаться.

## Что нужно

**4 штуки на одном листе, в один горизонтальный ряд, одинаково расставленных.**

Полка: третья, середина.

- размер каждого — **326 × 426 пикселей**, то есть пропорция **1 : 1,31** (ширина к высоте)
- размер указан **вместе с белой обводкой**
- **все 4 — одного габарита и одной формы**, отличается только дизайн: разные цвета и полоски на банке
- низ у всех на одной линии, верх тоже

Банка — цилиндр с крышкой сверху, силуэт у всех четырёх один.

## Обязательные требования

**Форма одна на всех.** Это один и тот же предмет с разными рисунками, а не 4 разных предмета.

**Дизайны различаются с одного взгляда**, в первую очередь по цвету. Игрок не должен вглядываться, чтобы понять, что перед ним два разных.

**Предмет занимает свой прямоугольник целиком** — без больших пустых полей сверху и снизу.

**Одинаковая белая обводка** у всех, одной толщины по всему контуру, примерно одна десятая ширины предмета. Обводка входит в габарит.

**Фон листа однотонный**, без текстуры и без теней под предметами: я режу каждый предмет отдельно, и тень уедет вместе с ним.

**Ноль текста.** Ни названий, ни брендов, ни цифр. Узоры, полоски, картинки вкуса — да; буквы — нет.

**Стиль тот же**, что у холодильника и коробки с карандашами: приглушённая палитра, тонкие линии, лёгкая бумажная текстура. Не мультяшно, не глянцево, не неон.

## Промпт для генерации

```
Sticker sheet: four identical cans in one horizontal row,
evenly spaced, standing upright.

CRITICAL: all four must be exactly the same shape and exactly the
same size — proportion width to height = 1:1.31. Only the design
differs: colour and pattern. All bottoms on one line, tops aligned.

Each can is a die-cut sticker with a thin white border of equal
thickness on all of them.

Plain flat background, no texture, no drop shadows. Muted palette,
soft paper texture on the illustration itself, clean modern flat style.
No text, no labels, no numbers, no brand names.
```
