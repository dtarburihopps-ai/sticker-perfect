# Бриф на арт — Sticker Perfect, уровень 1 «Канцелярский стол»

Для Себастиана. Игра — Telegram Mini App, вертикальный экран, эстетика vintage stationery.
Игрок тапает по стикеру внизу экрана и тапает по месту на столе — стикер перелетает и приклеивается.

## Что нужно, тремя частями

### Лист A — фон
Один файл: **рабочий стол, вид строго сверху**, полностью пустой.

Никаких предметов на нём. Совсем. Игра расставляет всё сама — если предметы будут нарисованы на фоне, играть будет нечем.
Тёплая бумажная поверхность, приглушённые цвета, лёгкая текстура. Ориентация вертикальная (примерно 3:4).

### Лист B — зоны и предметы, ВСЁ НА ОДНОМ ЛИСТЕ
Один файл, внутри — 12 объектов, разложенных сеткой с промежутками (потом нарежем).

Три ёмкости (зоны, куда игрок кладёт), вид сверху, **открытые сверху, пустые**:
1. стакан-карандашница — высокий, узкий
2. жестяная коробочка — маленькая, квадратная
3. деревянный лоток — плоский, широкий

Девять предметов:
4. карандаш · 5. ручка · 6. фломастер — длинные, узкие
7. скрепка · 8. канцелярская кнопка · 9. булавка — мелкие
10. конверт · 11. открытка · 12. почтовая марка — плоские, прямоугольные

**Почему одним листом:** так все объекты автоматически выходят в едином масштабе и стиле. Если генерировать по одному, скрепка получится размером с конверт, а стили не совпадут.

### Лист C — котик (можно позже)
Сидящий или спящий котик, вид сверху-сбоку, появляется в углу стола после прохождения.

## Обязательные требования

**Ракурс — строго сверху, одинаковый для всего.** Если стол нарисован сверху, а стакан сбоку — сцена развалится, и починить это можно только перерисовкой.

**Форма важнее красоты.** Силуэты должны отличаться разительно: длинное узкое / мелкое / плоское широкое. Именно по форме игрок без единого слова понимает, что куда. Не «улучшать» пропорции ради вида — уровень перестанет читаться.

**Каждый объект — как наклейка:** белая рамка-обводка по контуру (die-cut), мягкая тень. Без обводки это будет иконка, а не стикер.

**Фон под объектами — однотонный** (или прозрачность, если получится). Нужно вырезать каждый объект отдельным файлом.

**Ноль текста.** Ни надписей, ни цифр, ни логотипов, ни подписей — нигде.

**Размер:** каждый объект минимум 300 px по большой стороне, чтобы не мылился на телефоне.

**Стиль:** современная винтажная канцелярия. Тёплая приглушённая палитра, бумажные текстуры, аккуратность.
**Не** советское ретро. **Не** детский kawaii. **Не** мультяшные глазки и не яркий пластик.

**Никаких теней, привязанных к месту** — объекты будут двигаться по экрану, приклеенная тень выдаст подделку.

## Промпт для генерации (лист B)

```
Sticker sheet, flat lay, strict top-down view. Vintage stationery items as
die-cut stickers with white cut borders and soft drop shadows.
Grid layout with spacing between items, plain neutral background.
Items: tall narrow pencil cup, small square tin box, flat wide wooden tray,
pencil, pen, marker, paper clip, push pin, safety pin, envelope, postcard, postage stamp.
Muted warm palette, soft paper texture, clean modern illustration.
No text, no labels, no numbers. Consistent scale and lighting across all items.
```

## Что проверить в результате

- [ ] Все объекты в одном ракурсе — сверху
- [ ] Ёмкости пустые и открытые сверху
- [ ] Силуэты явно разные: длинное / мелкое / плоское
- [ ] У каждого объекта белая рамка-обводка
- [ ] Нигде нет текста
- [ ] Масштаб предметов согласован между собой
- [ ] Фон стола пустой
