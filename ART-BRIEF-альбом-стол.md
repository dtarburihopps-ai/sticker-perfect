# Бриф: альбом — стол с тетрадью

Для Себастиана. Одна картинка — вся сцена уровня. Наклейки к ней идут двумя отдельными листами.

## Что за уровень

Отсылка к нулевым: альбом с блестящими наклейками, который собирали и жалели клеить. Игрок раскладывает наклейки по развороту тетради: одна партия — на левую страничку, другая — на правую. Никакой головоломки: внутри странички любая наклейка идёт в любую рамку.

Разметка на страницах нужна не для загадки, а **для ровности**: наклейка садится в напечатанную рамку и встаёт вровень с соседями. Игра для перфекционистов, кривизна тут читается мгновенно.

Мест ровно столько же, сколько наклеек: пустых рамок в конце не остаётся.

## Что нужно

**Холст 900 × 1400**, вертикальный. Раскрытая тетрадь на столе, **вид строго сверху, без перспективы**.

- тетрадь занимает примерно **87% ширины холста**;
- **две одинаковые страницы**, между ними **пружина** — она и делает картинку тетрадью;
- бумага светлая, с **очень бледной клеткой** и лёгкой фактурой;
- у сгиба страницы чуть уходят в тень;
- вокруг — спокойный стол без мелких деталей;
- под тетрадью мягкая тень: она лежит на столе, а не наклеена на него.

## Разметка страниц — самое важное

На каждой странице **три ряда одинаковой высоты**, разделённые одинаковыми промежутками. В рядах напечатаны рамки под наклейки — тонкая двойная линия, как в альбомах нулевых.

**Левая страница сверху вниз:** одна широкая рамка во всю ширину, затем ряд из двух узких, затем ещё ряд из двух узких.

**Правая страница — тот же макет, перевёрнутый:** ряд из двух узких, ряд из двух узких, широкая рамка во всю ширину.

Итого **пять рамок на страницу, десять на разворот**.

**Все горизонтальные линии рядов обязаны совпадать на обеих страницах.** Смотришь на разворот — линии идут насквозь, как разлиновка. Это главное требование ко всей картинке: ради этой ровности уровень и существует.

Поля страницы и промежутки между рамками одинаковые со всех сторон, примерно **6% ширины страницы**.

## Пропорции рамок

- широкая: **ширина к высоте 1 : 0,89** — почти квадрат, чуть шире, чем выше;
- узкая: **1 : 1,90** — вертикальная, вдвое выше своей ширины.

Ровно эти же пропорции у наклеек: они заполняют рамки целиком.

## Обязательные требования

**Рамки пустые.** Наклеек на этой картинке быть не должно: их кладёт игра.

**Ноль текста.** Ни номеров под рамками, ни надписей на обложке.

**Стиль** как у остального арта игры: приглушённая палитра, мягкие края, лёгкая бумажная текстура. Не глянцево.

## Промпт для генерации

```
An open spiral notebook lying on a table, seen strictly from above,
flat, no perspective. Vertical image 900x1400.

Two identical pages with a metal spiral binding between them, light
paper with a very faint square grid, soft shadow near the fold, a calm
plain table around, a soft drop shadow under the notebook.

On each page: THREE ROWS OF EQUAL HEIGHT with printed empty sticker
frames drawn as a thin double line.
Left page from the top: one wide frame across the full width, then a
row of two narrow frames, then another row of two narrow frames.
Right page: the same layout upside down — two narrow, two narrow, one
wide.

CRITICAL: the horizontal row lines must match exactly on both pages,
so they read as continuous ruling across the spread.
Wide frame proportion width:height = 1:0.89, narrow frame = 1:1.90.
Equal margins everywhere, about 6% of the page width.

The frames are EMPTY — no stickers, no pictures inside.
Muted palette, soft paper texture, clean modern flat illustration.
No text, no numbers, no letters anywhere.
```

## Чеклист приёмки

- [ ] Вид строго сверху, без перспективы
- [ ] Пружина между страницами, страницы одинаковые
- [ ] По пять рамок на страницу, десять на разворот
- [ ] Слева «широкая / две / две», справа тот же макет перевёрнутый
- [ ] Линии рядов совпадают на обеих страницах
- [ ] Пропорции рамок 1 : 0,89 и 1 : 1,90
- [ ] Рамки пустые, текста нигде нет
